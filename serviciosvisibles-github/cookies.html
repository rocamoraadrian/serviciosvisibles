1. Qué son las cookies

Pequeños archivos que una web guarda en tu navegador para funcionar o recordar información.

2. Cookies que usa esta web

Esta web no usa cookies de análisis ni de publicidad. Solo carga recursos técnicos necesarios para mostrarse bien:

3. Cómo desactivarlas

Puedes bloquear o borrar cookies desde la configuración de tu navegador (Chrome, Firefox, Safari o Edge). Si bloqueas las técnicas, la web puede verse mal.
